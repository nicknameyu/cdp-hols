# CDP HOLs

This repository is to create Hands on labs for Cloudera Data Platform.

## Requirement
- These HOLs are written under UNIX shell. So, please use a bash or sh environment for running the commands.
- Terraform: Terraform is used to prepare the network and prerequisites of the Labs.
- CDP cli: [install CDP CLI](https://docs.cloudera.com/cdp-public-cloud/cloud/cli/topics/mc-installing-cdp-client.html)
- jq: Some commnands in the labs requires JQ to parse JSON output.
